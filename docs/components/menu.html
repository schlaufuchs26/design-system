Menu

A dropdown list of actions on Base UI. Arrow keys move, Enter selects and Escape closes.

Import

import { MenuButton } from "@schlaufuchs/react";

Example

<div class="fox-menu" role="menu">
  <button class="fox-menu-item" role="menuitem" type="button">Rename</button>
  <div class="fox-menu-separator"></div>
  <button class="fox-menu-item" role="menuitem" type="button" data-tone="danger">Delete</button>
</div>

Props

PropTypeDefaultNotes
trigger ReactElement (required) — Opens the menu.
items readonly MenuEntry[] (required) — label, onSelect, disabled, tone, separatorBefore, hint.
label string — A group label above the entries.
open / defaultOpen boolean — Controlled or uncontrolled visibility.
onOpenChange (open: boolean) => void — Called when it opens or closes.
side Side "bottom" Preferred side.

Accessibility

  • The popup is a menu; entries are menuitems with a highlight state.
  • A destructive entry sets tone=danger and keeps the same semantics.

Keyboard

  • ArrowDown/ArrowUp move the highlight; Home/End jump.
  • Enter or Space selects the highlighted entry.
  • Escape closes without selecting.
