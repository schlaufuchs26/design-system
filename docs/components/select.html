Select

A single-choice listbox on Base UI. Arrow keys, typeahead and Escape work without custom code.

Import

import { Select } from "@schlaufuchs/react";

Example

<div class="fox-field">
  <label class="fox-label" for="demo-filter">Filter</label>
  <select class="fox-select" id="demo-filter">
    <option>All runs</option>
    <option>Passed only</option>
  </select>
</div>

Props

PropTypeDefaultNotes
options readonly { value, label }[] (required) — The items to choose from.
label string (required) — Names the listbox.
value string — Controlled value; pair with onValueChange.
defaultValue string — Uncontrolled initial value.
onValueChange (value: string) => void — Called on every selection.
placeholder string "Select…" Shown while nothing is chosen.
disabled boolean — Blocks opening and focus.
name string — Submits the value with a form.

Accessibility

  • The trigger is a combobox; the popup is a listbox with aria-activedescendant tracking.
  • The chosen item is marked data-selected and repeats as the trigger's text.

Keyboard

  • ArrowDown opens the list; ArrowUp/Down move the highlight.
  • Enter selects, Escape closes without changing the value.
  • Typing letters jumps to the next matching option.
