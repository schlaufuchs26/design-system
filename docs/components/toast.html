Toast

A short message after an action, posted from anywhere inside the provider with useToast().

Import

import { ToastProvider, useToast } from "@schlaufuchs/react";

Example

Saved

The draft is safe

<div class="fox-toast">
  <div>
    <p class="fox-toast-title">Saved</p>
    <p class="fox-toast-description">The draft is safe</p>
  </div>
  <button class="fox-toast-close" aria-label="Dismiss" type="button">×</button>
</div>

Props

PropTypeDefaultNotes
ToastProvider children ReactNode (required) — Wraps the app; renders the viewport once.
useToast().add (toast: { title, description?, tone? }) => void — Posts a toast.
useToast().close (id: string) => void — Dismisses a toast early.
tone "accent" | "success" | "danger" "accent" Colours the left edge.

Accessibility

  • The viewport announces politely; a danger toast keeps the same live region.
  • The close button is hidden from the accessibility tree until the toast is expanded by hover or focus.

Keyboard

  • Focusing the toast expands it and reveals the close button.
