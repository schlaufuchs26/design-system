Switch

An immediate on/off setting, styled as a track and thumb. Use it for a setting that applies at once, not for a form choice.

Import

import { SwitchField } from "@schlaufuchs/react";

Example

<label class="fox-choice">
  <button class="fox-switch" data-checked role="switch" aria-checked="true" type="button">
    <span class="fox-switch-thumb"></span>
  </button>
  <span>Compact density</span>
</label>

Props

PropTypeDefaultNotes
label ReactNode (required) — The visible label and the accessible name.
checked / defaultChecked boolean — Controlled or uncontrolled state.
onCheckedChange (checked: boolean) => void — Called after every change.
disabled boolean — Blocks interaction.

Accessibility

  • role=switch with aria-checked; the thumb is decorative.
  • The track turns accent when on and keeps a 14px thumb for a visible position.

Keyboard

  • Space toggles the switch.
