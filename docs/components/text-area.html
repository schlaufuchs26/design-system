TextArea

The multi-line sibling of TextField, with the same label, hint and error wiring.

Import

import { TextArea } from "@schlaufuchs/react";

Example

<div class="fox-field">
  <label class="fox-label" for="demo-notes">Notes</label>
  <textarea class="fox-textarea" id="demo-notes" rows="3"></textarea>
</div>

Props

PropTypeDefaultNotes
label string (required) — Rendered as the label.
hint ReactNode — Helper text, linked by id.
error string — Marks the field invalid and renders the message.
rows number — Passed to the textarea.

Accessibility

  • Same label and error contract as TextField.
  • The control is resizable vertically, never horizontally.

Keyboard

  • Standard text editing keys; Enter inserts a newline.
