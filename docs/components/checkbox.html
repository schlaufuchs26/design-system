Checkbox

A single on/off choice with its label. The control is a Base UI checkbox with role=checkbox and a hidden input for forms.

Import

import { CheckboxField } from "@schlaufuchs/react";

Example

<label class="fox-choice">
  <button class="fox-checkbox" data-checked role="checkbox" aria-checked="true" type="button">
    <span class="fox-checkbox-indicator"></span>
  </button>
  <span>Notify me</span>
</label>

Props

PropTypeDefaultNotes
label ReactNode (required) — The visible label and the accessible name.
checked boolean — Controlled state.
defaultChecked boolean — Uncontrolled initial state.
onCheckedChange (checked: boolean) => void — Called after every change.
disabled boolean — Blocks interaction.
name / value string — Submitted with a form.

Accessibility

  • Wrapping label, so clicking the text toggles the box.
  • Checked state is exposed as aria-checked and as data-checked for styling.

Keyboard

  • Space toggles the focused box.
  • Tab moves to the next control.
