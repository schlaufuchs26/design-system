Radio group

One choice out of a few, in a fieldset with a legend. Arrow keys move the selection.

Import

import { RadioGroupField } from "@schlaufuchs/react";

Example

Tone 
<fieldset class="fox-choice-group">
  <legend class="fox-label">Tone</legend>
  <label class="fox-choice">
    <button class="fox-radio" data-checked role="radio" aria-checked="true" type="button">
      <span class="fox-radio-indicator"></span>
    </button>
    <span>Accent</span>
  </label>
  <label class="fox-choice">
    <button class="fox-radio" role="radio" aria-checked="false" type="button">
      <span class="fox-radio-indicator"></span>
    </button>
    <span>Neutral</span>
  </label>
</fieldset>

Props

PropTypeDefaultNotes
label string (required) — Rendered as the fieldset legend.
options readonly { value, label, disabled? }[] (required) — The choices.
value / defaultValue string — Controlled or uncontrolled selection.
onValueChange (value: string) => void — Called on every change.
disabled boolean — Disables the whole group.

Accessibility

  • The group is a fieldset with a legend, so the question is announced with each radio.
  • Only the selected radio is in the tab order.

Keyboard

  • Arrow keys move the selection through the group.
  • Tab leaves the group; Space selects the focused radio.
