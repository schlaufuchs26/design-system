Table

A table with the design system's row styles, an optional scroll wrapper and numeric cells in the mono face.

Import

import { Table, THead, TBody, Tr, Th, Td } from "@schlaufuchs/react";

Example

FeedUnread
Blog3
 
<div class="fox-table-wrap">
  <table class="fox-table" data-zebra>
    <thead><tr><th>Feed</th><th class="fox-num">Unread</th></tr></thead>
    <tbody><tr><td>Blog</td><td class="fox-num">3</td></tr></tbody>
  </table>
</div>

Props

PropTypeDefaultNotes
zebra boolean — Alternating row background.
scroll boolean true Wraps the table for horizontal scrolling.
caption ReactNode — A table caption, announced by screen readers.
Th / Td numeric boolean — Right-aligns and uses the mono face.

Accessibility

  • Header cells are scoped to their column by default.
  • A caption is the accessible table name; use it when the heading above is not enough.
