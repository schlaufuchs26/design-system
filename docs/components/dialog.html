Dialog

A modal on Base UI. Focus moves into the popup, Tab stays inside, Escape closes it and focus returns to the trigger.

Import

import { Dialog } from "@schlaufuchs/react";

Example

Rename session

A short explanation.
<div class="fox-dialog" role="dialog" aria-modal="true" aria-labelledby="demo-dialog-title">
  <div class="fox-dialog-header">
    <h2 class="fox-dialog-title" id="demo-dialog-title">Rename session</h2>
  </div>
  <div class="fox-dialog-body">A short explanation.</div>
  <div class="fox-dialog-footer">
    <button class="fox-button" data-variant="outline">Cancel</button>
    <button class="fox-button" data-variant="solid">Save</button>
  </div>
</div>

Props

PropTypeDefaultNotes
trigger ReactElement (required) — Gets the trigger props merged in.
title string (required) — Names the dialog.
description ReactNode — Shown under the title and linked to the dialog.
children ReactNode — The body.
footer ReactNode — Actions; usually a Cancel and a primary button.
open / defaultOpen boolean — Controlled or uncontrolled visibility.
onOpenChange (open: boolean) => void — Called when it opens or closes.
closeLabel string "Close" Accessible name of the corner button.

Accessibility

  • role=dialog with aria-modal, titled by the title element.
  • The backdrop is a real element, so a click outside closes the dialog.
  • Focus is trapped while open and returns to the trigger on close.

Keyboard

  • Escape closes the dialog.
  • Tab and Shift+Tab cycle inside the popup.
  • Enter activates the focused button.
