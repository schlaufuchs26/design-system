Badge

A small status label with a tone from the status palette. Monospace is for counts and IDs.

Import

import { Badge } from "@schlaufuchs/react";

Example

ok error 3 
<span class="fox-badge" data-tone="success">ok</span>
<span class="fox-badge" data-tone="danger" data-outline>error</span>
<span class="fox-badge" data-tone="neutral" data-mono>3</span>

Props

PropTypeDefaultNotes
tone "neutral" | "accent" | "info" | "queued" | "success" | "warning" | "danger" "neutral" Background and text from the status tokens.
outline boolean — Transparent fill with a current-colour border.
mono boolean — Mono face and tabular numbers.

Accessibility

  • A badge is text, not a control; the tone never carries meaning alone, the label says it.
