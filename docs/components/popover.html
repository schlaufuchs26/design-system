Popover

A non-modal panel anchored to a trigger. Use it for details or a small form; it does not trap focus.

Import

import { PopoverPanel } from "@schlaufuchs/react";

Example

What is this?

A short explanation.

<div class="fox-popover">
  <p class="fox-popover-title">What is this?</p>
  <p class="fox-popover-description">A short explanation.</p>
</div>

Props

PropTypeDefaultNotes
trigger ReactElement (required) — Anchors the panel.
title / description string / ReactNode — Optional heading and lead text.
children ReactNode — The panel body.
open / defaultOpen boolean — Controlled or uncontrolled visibility.
onOpenChange (open: boolean) => void — Called when it opens or closes.
side "top" | "bottom" | "left" | "right" "bottom" Preferred side; it flips when there is no room.

Accessibility

  • The popup is a dialog with the title as its name.
  • Focus is not trapped; Tab leaves the panel.
  • Escape and a click outside close it.

Keyboard

  • Enter or Space on the trigger opens it.
  • Escape closes it.
