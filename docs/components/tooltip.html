Tooltip

A short hint on hover or focus. The wrapper adds role=tooltip and aria-describedby, which Base UI 1.9 leaves to the consumer.

Import

import { TooltipHint, TooltipProvider } from "@schlaufuchs/react";

Example

Saves the draft 
<span class="fox-tooltip">Saves the draft</span>

Props

PropTypeDefaultNotes
trigger ReactElement (required) — The element the hint describes.
content ReactNode (required) — Short text, never interactive content.
side "top" | "bottom" | "left" | "right" "top" Preferred side.
open / defaultOpen boolean — Controlled or uncontrolled visibility.
TooltipProvider delay number 400 Shared delay in ms for grouped tooltips.

Accessibility

  • The popup carries role=tooltip and the trigger points at it with aria-describedby.
  • The trigger keeps its own name; a tooltip is not a substitute for a label.

Keyboard

  • Focusing the trigger shows the hint; Escape hides it.
