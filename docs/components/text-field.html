TextField

A labelled input with a hint and an error. The label, hint and error are wired to the input by generated ids.

Import

import { TextField } from "@schlaufuchs/react";

Example

As it appears on the card

<div class="fox-field">
  <label class="fox-label" for="demo-name">Name</label>
  <input class="fox-input" id="demo-name" aria-describedby="demo-name-hint" />
  <p class="fox-hint" id="demo-name-hint">As it appears on the card</p>
</div>

Props

PropTypeDefaultNotes
label string (required) — Rendered as the label.
hint ReactNode — Helper text below the input, linked with aria-describedby.
error string — Sets aria-invalid and renders a role=alert message.
id string — Generated when omitted; pass one to link an external label.
...rest input attributes — value, onChange, placeholder, type, disabled.

Accessibility

  • Every field has a visible label; the placeholder is not a label.
  • The error text is announced as an alert and the input carries aria-invalid.
  • Focus uses the accent border and a 3px accent-subtle ring.

Keyboard

  • Standard text editing keys; Tab leaves the field.
