Components

Typed React components from @schlaufuchs/react, styled by the plain CSS classes in @schlaufuchs/tokens. Every page lists the props, the markup and the keyboard contract.

Button The main action control. Variants and sizes come from the token scale; the element is a native button, so Enter and Space work without code. IconButton A square button for a single glyph. The accessible name is a required prop because there is no visible text. TextField A labelled input with a hint and an error. The label, hint and error are wired to the input by generated ids. TextArea The multi-line sibling of TextField, with the same label, hint and error wiring. Select A single-choice listbox on Base UI. Arrow keys, typeahead and Escape work without custom code. Checkbox A single on/off choice with its label. The control is a Base UI checkbox with role=checkbox and a hidden input for forms. Switch An immediate on/off setting, styled as a track and thumb. Use it for a setting that applies at once, not for a form choice. Radio group One choice out of a few, in a fieldset with a legend. Arrow keys move the selection. Dialog A modal on Base UI. Focus moves into the popup, Tab stays inside, Escape closes it and focus returns to the trigger. Popover A non-modal panel anchored to a trigger. Use it for details or a small form; it does not trap focus. Tooltip A short hint on hover or focus. The wrapper adds role=tooltip and aria-describedby, which Base UI 1.9 leaves to the consumer. Menu A dropdown list of actions on Base UI. Arrow keys move, Enter selects and Escape closes. Tabs A tab list and its panels. The roving tab stop follows the arrow keys and only the active panel is in the tab order. Table A table with the design system's row styles, an optional scroll wrapper and numeric cells in the mono face. Toast A short message after an action, posted from anywhere inside the provider with useToast(). Badge A small status label with a tone from the status palette. Monospace is for counts and IDs. Card A surface with a header, body and footer. The header and footer take actions; the body holds content. Stack, Row and Grid The three layout helpers. Gaps are token steps (1=4px … 16=64px), never raw pixel values.
