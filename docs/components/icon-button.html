IconButton

A square button for a single glyph. The accessible name is a required prop because there is no visible text.

Import

import { IconButton } from "@schlaufuchs/react";

Example

<button class="fox-button" data-size="icon" data-variant="ghost" aria-label="Close">×</button>

Props

PropTypeDefaultNotes
aria-label string (required) — The name screen readers announce; there is no visible text.
variant "solid" | "outline" | "ghost" | "danger" "ghost" Ghost keeps toolbars quiet.

Accessibility

  • Requires aria-label; a tooltip can repeat the label but never replaces it.
  • Renders a 36×36 button from the md control step.

Keyboard

  • Enter or Space activates it.
