Card

A surface with a header, body and footer. The header and footer take actions; the body holds content.

Import

import { Card, CardHeader, CardBody, CardFooter } from "@schlaufuchs/react";

Example

Feeds
4 feeds, 34 unread
<section class="fox-card" data-elevated>
  <header class="fox-card-header"><span class="fox-card-title">Feeds</span></header>
  <div class="fox-card-body">4 feeds, 34 unread</div>
  <footer class="fox-card-footer"><button class="fox-button" data-variant="outline">Scan</button></footer>
</section>

Props

PropTypeDefaultNotes
elevated boolean — Raised background and a small shadow.
accent boolean — Accent-tinted border.
padding "none" | "sm" | "md" — Body padding; none lets a table run edge to edge.
CardHeader title ReactNode — Rendered in the card title style.

Accessibility

  • Sections and headings stay the consumer's job; use a real heading inside the header when the card is a landmark.
